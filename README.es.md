## Open source

### [ddd_value_objects](https://github.com/JoshuaAivodji/ddd_value_objects)
[![pub package](https://img.shields.io/pub/v/ddd_value_objects.svg)](https://pub.dev/packages/ddd_value_objects)

Value Objects listos para usar en Domain-Driven Design con Dart: email, contraseña, nombre, edad, URL, nombre de usuario. Inmutables, validados con `Either`, mensajes de error en inglés y francés, más de 159 tests.

### [phone_input_plus](https://github.com/JoshuaAivodji/phone_input_plus)
[![pub package](https://img.shields.io/pub/v/phone_input_plus.svg)](https://pub.dev/packages/phone_input_plus)

Un campo de entrada telefónica para Flutter: detección automática del país, formato en tiempo real, validación específica para cada país. Cubre los 52 países africanos y funciona en cualquier parte del mundo.

## Cómo trabajo

- **La arquitectura primero.** Clean Architecture, DDD y SOLID en cada proyecto, sea cual sea su tamaño.
- **Los tests son parte del trabajo.** Una funcionalidad está terminada cuando está probada, no antes.
- **Entrega continua.** CI/CD, entornos de desarrollo y producción separados, revisión de código en cada cambio.
- **La IA, en el código y en el producto.** La uso para entregar más rápido sin sacrificar la calidad, y la integro en las aplicaciones para crear funcionalidades inteligentes.
