## Open source

### [ddd_value_objects](https://github.com/JoshuaAivodji/ddd_value_objects)
[![pub package](https://img.shields.io/pub/v/ddd_value_objects.svg)](https://pub.dev/packages/ddd_value_objects)

Ready-to-use Value Objects for Domain-Driven Design in Dart: email, password, name, age, URL, username. Immutable, validated with `Either`, error messages in English and French, 159+ tests.

### [phone_input_plus](https://github.com/JoshuaAivodji/phone_input_plus)
[![pub package](https://img.shields.io/pub/v/phone_input_plus.svg)](https://pub.dev/packages/phone_input_plus)

A phone input field for Flutter: automatic country detection, real-time formatting, country-specific validation. It covers all 52 African countries and works anywhere in the world.

## How I work

- **Architecture first.** Clean Architecture, DDD and SOLID on every project, whatever its size.
- **Tests are part of the job.** A feature is done when it is tested, not before.
- **Continuous delivery.** CI/CD, separate development and production environments, code review on every change.
- **AI, in the code and in the product.** I use it to ship faster without compromising on quality, and I build it into applications to create smart features.
